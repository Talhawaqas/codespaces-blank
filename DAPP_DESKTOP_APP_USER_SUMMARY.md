# Inaya Network is now available as a desktop app

The main dApp — faucet, node registry, staking, KYC, and referrals — now runs as a real app on your computer, not just in a browser tab.

## What you get

- **A real installed app** with its own icon, Start Menu entry, and taskbar presence — just like any other program on your computer.
- **Runs in the background.** Closing the window doesn't quit it — it keeps running quietly in your system tray. Click the tray icon to bring it back.
- **Automatic updates.** When a new version is released, the app will ask if you'd like to install it — one click and you're up to date.
- **Connect your wallet with WalletConnect.** Since this is a standalone app rather than a browser tab, MetaMask/Trust Wallet/Coinbase Wallet (which rely on a browser extension) aren't available inside it. The app detects this automatically and leads with WalletConnect instead — scan the QR code with your wallet app and you're connected, same as pairing a wallet on any other WalletConnect-enabled site.

Everything else — the faucet, staking, node registry, KYC verification, referrals — works exactly the same as it does in your browser today. This is the same dApp, just in its own window.

## This is a separate app from Business Workspace

If you've already installed the Inaya Business Workspace desktop app, this is a different, standalone app — its own installer, its own updates. Get both from the same [download page](/download).

## Available for

- **Windows** — ready now, tested with a real wallet connection end-to-end. You may see a Windows SmartScreen warning ("Windows protected your PC") when installing — this is expected for now, not a sign of a problem. It shows up because the installer isn't digitally signed with a paid certificate yet; we're deferring that cost until mainnet. Click "More info" → "Run anyway" to proceed.
- **Linux** — available now. A real user tested it and reported a visual glitch where dropdown menus showed a bright orange glow that looked like an error — that's now fixed. Still hasn't had a full pass on real Linux hardware beyond that, so please keep the reports coming.

(macOS isn't available yet.)

## We're on testnet — please report anything odd

This is an early release. We already caught and fixed two real bugs ourselves before wide release (a wallet-payment button that silently did nothing, and a Linux dropdown that glowed orange like an error) — but if you hit something that looks wrong or behaves differently than the website, please tell us. That's exactly the feedback we need right now.
