# Master Defect Registry

Whole-codebase SQA engagement, started 2026-09-26. Severity scale S0 (critical) to S4 (informational). Status flow: OPEN, CONFIRMED, IN PROGRESS, FIXED, REGRESSION TESTED, VERIFIED. Evidence for every entry is an automated test in this repository that fails on the old behavior and passes on the new. "VERIFIED" means the regression test passed against the real database (and, for SQA-005, against the real compiled contract). Nothing has been deployed yet; deployment verification is a separate step.
