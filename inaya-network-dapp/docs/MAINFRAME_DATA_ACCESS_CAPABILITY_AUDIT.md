# Mainframe & Legacy Data Access + Real-Time SQL Virtualization — Phase 0 Audit

**SOW:** Inaya Mainframe & Legacy Data Access + Real-Time SQL Virtualization (Software AG CONNX-inspired). **Status:** Mandatory pre-implementation audit, completed before any implementation code was written, per the SOW's own governing rule (AUDIT → REUSE → CONNECT → IMPLEMENT ONLY GENUINE GAPS → TEST REAL SYSTEMS → SECURE → INTEGRATE → PROVE → DOCUMENT LIMITATIONS).

## Mandatory rule compliance

Nothing classified above as already existing was rebuilt. The connector abstraction reuses `pinningProviders/`'s shape; the credential store reuses `backupCryptoAndCredentials.js`'s envelope-encryption shape and per-secret-class-key rule; the admin UI reuses `CloudBackupSchedulerView.js`/`IntegrationsView.js`'s conventions; permissions reuse the existing org-gate pattern; audit reuses `logOrgActivity` directly.

## The one architectural finding that shapes this pass

**No Adabas, VSAM, IMS, or RMS/OpenVMS environment exists anywhere in this session's reach.** Per the SOW's own repeated, explicit rules ("Do not implement a fake VSAM parser... and call it production VSAM support," "Do not fabricate mainframe test evidence," "Do not use mock connectors as proof of enterprise compatibility"), none of the four named mainframe connectors are implemented this pass. What *is* built this pass — the connector framework, credential store, metadata/virtual-schema engine, SQL gateway with a real parser and real query execution, permission/audit integration, admin UI, and SQL console — is real, generic infrastructure, proven end-to-end against a genuinely real (if non-mainframe) SQL data source, so that implementing any of the four mainframe connectors later is a scoped "implement this one interface" task rather than a from-scratch platform build. This is documented honestly in the completion report using the SOW's own Section 47 claim categories (Verified / Tested with fixture / Compatible by protocol / Planned / External dependency) rather than glossed over.
