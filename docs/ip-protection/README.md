## What still needs the user (per the SOW's own priority order and scope principle)

1. **Confirm the intended owning entity** — the exact legal name and registration status of the Inaya company/entity that IP should be assigned to. Every draft agreement in this folder uses a placeholder (`[INAYA LEGAL ENTITY NAME]`) until this is confirmed.
2. **Engage a qualified Pakistani IP lawyer** to review the two agreement templates, confirm the copyright and trademark filing details, and handle the actual IPO-Pakistan submissions — none of that was done here, per the SOW's own explicit scope boundary.
3. **Collect signatures** on the founder and contributor agreements once the templates are reviewed.
4. **Run the official IPO-Pakistan trademark register search** (ipo.gov.pk/trademark_registry) — this session only ran an informal public web search, which is not a substitute.
5. **Decide which copyright works to actually file**, using the prioritized list in `04-copyright-registration-plan.md` as a starting point, not a final answer.
